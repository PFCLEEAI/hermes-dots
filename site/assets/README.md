# Hero asset

An original illustration generated with Codex's built-in image generation tool for this project. No reference images were used. The prompt was:

> Use case: stylized-concept. Asset type: original abstract landing-page hero illustration for hermes-dots, 1600x900 landscape. A constellation of soft glowing dots connected by delicate thin lines, against a calm dark-navy-to-indigo gradient background. Minimal, spacious, softly luminous, restrained and elegant; a loose organic network of dots with varying subtle blue, lavender and pale-white glows. No text, no letters, no logos, no people, no recognizable brand symbols, no watermark. Opaque background. Output a 1600x900 image.

Exports: `hero.png` and `hero.webp` are 1600×900; `hero-readme.webp` is 1200×675. The generated source was resized for these dimensions. The PNG uses a 64-color palette to stay below 500 KB; the WebP copies were compressed from the full-color source. Export tooling is not a runtime dependency or a site build step.
